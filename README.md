## About

I'm an AI Engineer working across the full LLM stack — model training and fine-tuning, retrieval-augmented generation, and autonomous agent systems built to run reliably in production, not just in a notebook. My approach is systems-first: every model or agent I build is designed around how it fails, scales, and gets maintained, not just how it performs on day one.
