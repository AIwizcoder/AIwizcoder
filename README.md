My work centers on LLM engineering: building agentic workflows, retrieval-augmented systems, and automation pipelines that hold up under real usage, not just in a notebook.

| Area | What I actually do |

| 🤖 **AI Agents & Automation** | Designing multi-agent workflows and autonomous pipelines with LangChain and LangGraph |
