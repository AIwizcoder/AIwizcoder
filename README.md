### 👋 About Me

I'm an **AI Engineer** focused on building AI systems that do real work, not demos. My background sits at the intersection of quantitative finance and full-stack AI product engineering — I specialize in taking an LLM-powered prototype and turning it into something reliable enough to run unattended in production.

- ⚙️ **Core focus:** LLM agent systems, RAG pipelines, and data-intensive backends
- 🧮 **Domain depth:** Quantitative finance — OHLCV processing, correlation analysis, and market data pipelines at scale
- 🏗️ **What I build:** End-to-end systems — Flask/PostgreSQL backends, async job pipelines, multi-agent orchestration
- 🎯 **Right now:** Building out a portfolio of production-grade AI agent systems and taking on freelance AI engineering work

<br/>

### 🚧 Currently Building

**AR / Collections Agent** — an autonomous, async agent that monitors overdue invoices, sends escalating follow-up communications, negotiates simple payment plans, and reports recovered amounts.
*Flagship portfolio project — in progress.*

Alongside it, I'm rebuilding this GitHub into a proper engineering portfolio and sharpening core CS fundamentals (DSA / algorithms) day by day.
